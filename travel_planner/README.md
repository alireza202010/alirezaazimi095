# سفرپلنر — پیشنهاددهنده هوشمند سفر داخلی و خارجی (MVP)

کاربر بودجه، تاریخ رفت و برگشت (شمسی)، تعداد بزرگسال و کودک، نوع سفر و علایقش را وارد می‌کند و سیستم
از بین ۳۸ مقصد (۱۷ داخلی، ۲۱ خارجی) بهترین‌ها را با این خروجی پیشنهاد می‌دهد:
امتیاز، سطح رفاه ممکن با بودجه، هزینه کل و نفری با جزئیات، وضعیت ویزا، مناسب بودن فصل،
دلایل پیشنهاد، هشدارها، جاذبه‌ها و **برنامه روزبه‌روز** با تاریخ شمسی.

## اجرا

```bash
cd travel_planner
python -m pip install -r requirements.txt
python -m uvicorn trip.main:app --reload --port 8001
# http://127.0.0.1:8001
```

تست‌ها (داخل پوشه `travel_planner`): `python -m pytest -q`

## ⚠️ درباره داده‌ها
- مقصدها و جاذبه‌ها واقعی‌اند، اما **قیمت‌ها تخمینی** و به دلار ذخیره شده‌اند و با «نرخ دلار امروز» که کاربر وارد
  می‌کند به تومان تبدیل می‌شوند (پیش‌فرض با متغیر محیطی `DEFAULT_USD_RATE`).
- **وضعیت ویزا برای گذرنامه ایرانی** بر اساس آخرین اطلاعات موجود و محتاطانه ثبت شده و ممکن است تغییر کرده باشد.
- همه چیز در `data/destinations.json` قابل ویرایش است (قیمت‌ها، فصل‌ها، ویزا، جاذبه‌ها، نکات). مقصد جدید را
  با همان ساختار اضافه کنید؛ هنگام اجرا اعتبارسنجی می‌شود.

| فیلد | توضیح |
|---|---|
| `tags` | میزان تناسب با هر علاقه (۰ تا ۱): nature, beach, history, shopping, food, adventure, relaxation, entertainment, pilgrimage, ski, desert |
| `good_for` | family, couple, friends, solo |
| `season` | امتیاز ۱ تا ۵ برای هر ماه میلادی (ژانویه تا دسامبر) |
| `min_days` / `max_days` | حداقل روز لازم / تعداد روز کافی |
| `lodging_usd` | قیمت هر اتاق در شب (economy / standard / luxury) |
| `daily_usd` | هزینه روزانه هر نفر: غذا، جابه‌جایی، تفریحات |
| `transport_usd` | رفت و برگشت هر بزرگسال از تهران |
| `visa` | domestic, free, on_arrival, required, embassy |

## منطق پیشنهاد (`trip/recommender.py`, `trip/costs.py`)
1. **فیلترها:** داخلی/خارجی، فقط بدون ویزا، حداکثر ساعت مسیر، حداقل روز لازم برای مقصد، آب‌وهوای خیلی نامناسب، هم‌خوانی خیلی کم با علایق.
2. **هزینه:** رفت‌وبرگشت + اقامت (تعداد اتاق بر اساس ترکیب نفرات) + هزینه روزانه + ویزا + ۱۰٪ پیش‌بینی‌نشده؛
   کودکان با ضریب کمتر؛ **نوروز** (۱ تا ۱۳ فروردین) ۳۵٪ گران‌تر و اوج فصل مقصد ۱۵٪ گران‌تر برای اقامت.
3. **سطح رفاه:** در حالت خودکار بهترین سطحی که در بودجه جا شود (لوکس ← استاندارد ← اقتصادی)؛ تا ۱۰٪ بیش از بودجه با هشدار نمایش داده می‌شود.
4. **امتیاز:** ۴۰٪ علایق + ۲۵٪ فصل + ۱۵٪ سطح رفاه ممکن + ۱۰٪ تناسب مدت سفر + ۱۰٪ تناسب با نوع همسفران.
5. **برنامه روزبه‌روز:** جاذبه‌های مرتبط با علایق کاربر زودتر، روز اول سبک، روز آخر خرید سوغات و بازگشت.

## API
- `POST /api/recommend` — دریافت پیشنهادها (مستندات کامل: `/docs`)
- `GET /api/destinations` — همه مقصدها
- `GET /api/meta` — برچسب‌ها و نرخ پیش‌فرض دلار

## قدم‌های بعدی پیشنهادی
قیمت لحظه‌ای پرواز و هتل از API آژانس‌ها، مبدأ‌های غیر از تهران، سفرهای چندشهره، ذخیره و اشتراک‌گذاری برنامه،
خروجی PDF، و اتصال به رزرو برای کسب درآمد از کمیسیون.
