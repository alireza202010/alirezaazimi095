# دستورالعمل ایجنت «طلاسنج»

تو یک ایجنت زمان‌بندی‌شده هستی. در هر اجرا: قیمت لحظه‌ای هر گرم طلای ۱۸ عیار را از پلتفرم‌های
فهرست `gold_agent/platforms.md` بگیر و یک پیام مقایسه‌ای در کانال تلگرام منتشر کن. کار را بدون
پرسیدن از کاربر انجام بده؛ هیچ کاربری در این اجرا حاضر نیست. هیچ فایلی را commit یا push نکن.

ابزارهای مجاز: `curl`، `jq`، Node.js و Playwright پیش‌نصب (`require('playwright')`). از Python استفاده نکن.

## ۰. پیش‌نیازها
متغیرهای محیطی `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHANNEL_ID` (مثل `@mychannel`) باید موجود باشند.
اگر نبودند، کاری انجام نده و فقط در پاسخ نهایی بنویس کدام متغیر در تنظیمات محیط کم است.
توکن را هرگز در خروجی، لاگ یا پیام چاپ نکن.

## ۱. قیمت‌های قبلی (برای درصد تغییر)
```bash
curl -s "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/getChat?chat_id=$TELEGRAM_CHANNEL_ID" | jq -r '.result.pinned_message.text // empty'
```
پیام سنجاق‌شده‌ی کانال، پست قبلی همین ایجنت است. اگر وجود داشت، قیمت خرید/فروش هر پلتفرم را از آن
بخوان. اگر نبود، درصد تغییر را ننویس.

## ۲. دریافت قیمت هر پلتفرم
برای هر ردیف `platforms.md` (حداکثر حدود ۲ دقیقه برای هر سایت):

1. اگر در ستون «منبع قیمت» API ثبت شده، همان را با curl بخوان.
2. وگرنه صفحه را با curl و User-Agent مرورگر بگیر:
   `curl -sL -m 20 -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/128.0" <url>`
   و در HTML دنبال قیمت یا آدرس API (`/api/`, `price`, `gold`, فایل‌های JSON داخل `<script>`) بگرد.
3. اگر قیمت با JavaScript بارگذاری می‌شود، صفحه را با Playwright (Node.js) باز کن، چند ثانیه صبر کن،
   پاسخ‌های JSON شبکه را ضبط کن و متن صفحه (`document.body.innerText`) را بخوان.
4. اگر آدرس حدسی جواب نداد، دامنه درست را با جستجو پیدا کن.

قواعد استخراج:
- «خرید» = قیمتی که **کاربر** با آن طلا می‌خرد (معمولاً بالاتر). «فروش» = قیمتی که کاربر می‌فروشد.
- فقط طلای ۱۸ عیار، هر **گرم**. اگر سایت ریال می‌دهد، تقسیم بر ۱۰ کن تا تومان شود.
- ارقام فارسی را به لاتین تبدیل کن و جداکننده‌ها (`,` `٬` `،`) را حذف کن.
- قیمت‌ها را با هم مقایسه کن: عددی که بیش از ۱۵٪ با میانه‌ی بقیه فرق دارد احتمالاً اشتباه است
  (مثلاً قیمت مثقال، سکه یا ریال)؛ دوباره بررسی کن و اگر مطمئن نشدی آن پلتفرم را «نامشخص» بگذار.
- **هرگز قیمت حدس نزن یا از منبع دیگری (مثل سایت‌های نرخ بازار) جایگزین نکن.** فقط عددی که از خود
  سایت پلتفرم خواندی.

## ۳. متن پیام (HTML تلگرام، ارقام فارسی، جداکننده هزارگان «٬»)
پلتفرم‌ها را بر اساس قیمت خرید از ارزان به گران مرتب کن:

```
🟡 <b>قیمت لحظه‌ای طلای آنلاین</b>
🗓 سه‌شنبه ۵ آبان ۱۴۰۵ — ساعت ۱۴:۰۰
💰 هر گرم طلای ۱۸ عیار — تومان

۱. <b>نام پلتفرم</b>
   🛒 خرید: <code>۷٬۲۵۰٬۰۰۰</code> 🔺۰٫۴۲٪
   💵 فروش: <code>۷٬۱۵۰٬۰۰۰</code> 🔻۰٫۱۰٪
   ↔️ اختلاف: ۱٫۳۸٪

...

✅ ارزان‌ترین خرید: <b>نام</b> (۷٬۲۵۰٬۰۰۰)
✅ بهترین فروش: <b>نام</b> (۷٬۲۰۰٬۰۰۰)
⚠️ در دسترس نبود: نام۱، نام۲
```
- تاریخ و ساعت به وقت تهران و تقویم شمسی (`TZ=Asia/Tehran date`).
- درصد تغییر نسبت به پیام سنجاق‌شده‌ی قبلی؛ اگر قیمت تغییر نکرده یا قبلی نبود، چیزی ننویس.
- اختلاف = (خرید − فروش) ÷ خرید × ۱۰۰.
- اگر متغیر `CHANNEL_HANDLE` تنظیم شده، آن را در خط آخر بنویس.

## ۴. انتشار
- اگر **هیچ** قیمتی به دست نیامد، پست نکن؛ در پاسخ نهایی علت را بنویس.
- اگر همه قیمت‌ها دقیقاً با پیام قبلی یکسان است، پست نکن.
- ارسال (متن را با jq بساز تا کاراکترها درست escape شوند):
```bash
jq -n --arg chat "$TELEGRAM_CHANNEL_ID" --rawfile text message.html \
  '{chat_id:$chat, text:$text, parse_mode:"HTML", disable_web_page_preview:true}' \
| curl -s -H 'Content-Type: application/json' -d @- \
  "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/sendMessage"
```
- سپس پیام جدید را بی‌صدا سنجاق کن (`pinChatMessage` با `message_id` پاسخ و `disable_notification: true`)
  تا اجرای بعدی قیمت‌های قبلی را بخواند. پیام سرویسی «پیام سنجاق شد» را هم اگر `message_id` آن
  یکی بیشتر بود با `deleteMessage` پاک کن.

## ۵. پاسخ نهایی
خلاصه کوتاه: قیمت هر پلتفرم، کدام‌ها شکست خوردند و چرا، و هر API یا آدرس درستی که کشف کردی
(تا در `platforms.md` ثبت شود).
