# طلاسنج — ایجنت زمان‌بندی‌شده Claude برای کانال قیمت طلا

بدون هیچ کد و سروری: یک **scheduled task** در claude.ai هر ساعت یک نشست تازه‌ی Claude باز می‌کند،
آن نشست [`AGENT.md`](AGENT.md) را می‌خواند، قیمت طلای ۱۸ عیار را از پلتفرم‌های
[`platforms.md`](platforms.md) می‌گیرد و با Bot API در کانال تلگرام پست می‌کند.
قیمت‌های پست قبلی از پیام سنجاق‌شده‌ی کانال خوانده می‌شود (بدون دیتابیس).

## راه‌اندازی
1. در تلگرام از `@BotFather` با `/newbot` یک بات بسازید.
2. بات را ادمین کانال کنید با دسترسی ارسال، سنجاق و حذف پیام.
3. در claude.ai → تنظیمات محیط ابری (منوی محیط در نوار عنوان نشست → Edit):
   - **Network access**: دامنه‌های `api.telegram.org` و همه دامنه‌های `platforms.md` را مجاز کنید
     (یا سطح دسترسی کامل).
   - **متغیرها/Secrets**: `TELEGRAM_BOT_TOKEN`، `TELEGRAM_CHANNEL_ID` (مثل `@mychannel`) و اختیاری `CHANNEL_HANDLE`.
4. scheduled task «طلاسنج» را فعال کنید.

## تغییر رفتار
- لیست پلتفرم‌ها، آدرس‌ها یا API کشف‌شده: `platforms.md`
- قالب پیام و قواعد: `AGENT.md`
- زمان‌بندی: از تنظیمات scheduled task (حداقل هر ۱ ساعت).

## محدودیت‌ها
- هر اجرا یک نشست کامل Claude است و از سهمیه‌ی حساب مصرف می‌کند.
- سایت‌هایی که IP خارج از ایران را مسدود می‌کنند از این محیط جواب نمی‌دهند و در پیام «در دسترس نبود» می‌آیند.
